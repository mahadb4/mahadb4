## About Me

I'm a Computer Science student at SZABIST Karachi who builds backend systems and AI-powered applications, and I like taking them from code to a deployed, tested service.

- **Backend:** REST APIs with Django REST Framework and PostgreSQL, including authentication, role-based authorization, pagination, search, and Redis caching.
- **AI:** RAG applications using pgvector and Gemini, plus multi-agent AI workflows in mobile apps.
- **Cloud & DevOps:** Docker, GitHub Actions CI/CD, and AWS (S3, RDS, ECR, ECS/Fargate, CloudWatch, EC2).
- **Full-stack:** React, TypeScript, and React Native apps backed by Django, Node.js, NestJS, Supabase, and Firebase.
- **Leadership:** Six years of team leadership and client management, which shapes how I communicate, prioritize, and own outcomes.
